# C++ Advanced Project Manager

This project is a command-line project management system written in C++.

It manages projects, team members, specialized tasks, task assignments, budgets, and exception handling. The program demonstrates object-oriented programming concepts such as inheritance, polymorphism, multiple inheritance, dynamic memory allocation, and custom exceptions.

## Features

- Create and manage multiple projects
- Create software projects and research projects
- Add team members with roles and task limits
- Add different task types:
  - Development tasks
  - Testing tasks
  - Documentation tasks
- Assign tasks to team members
- Display all projects and their tasks
- Display all team members and their assigned tasks
- Filter tasks by status
- Track project budgets
- Handle invalid operations with custom exceptions

## Concepts Used

- Classes and objects
- Inheritance
- Polymorphism
- Multiple inheritance
- Abstract classes
- Virtual functions
- Custom exception classes
- Dynamic memory allocation
- Arrays of pointers
- Copy constructors
- Destructors
- Encapsulation
